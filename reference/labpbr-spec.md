# LabPBR 1.3 规范速查

来源：shaderLABS wiki — LabPBR Material Standard（v1.3，2026-02-20 更新）
https://shaderlabs.org/wiki/LabPBR_Material_Standard

注意：Iris 只负责加载 `_n` / `_s`，如何解读由光影包决定。不同光影包对 LabPBR 的支持程度不同（例如部分光影不支持预设金属）。

## _n 法线贴图

格式：**DirectX（Y-）**，R 向右，G 向下。

| 通道 | 含义 | 编码 |
|---|---|---|
| R | 法线 X | 0 = 左，255 = 右 |
| G | 法线 Y | 0 = 上，255 = 下（DirectX） |
| B | 环境光遮蔽 AO | 线性；0 = 100% 遮蔽，255 = 无遮蔽 |
| A | 高度 | 线性；0 = 25% 深度，255 = 0% 深度（表面最高点） |

- 法线 Z 由光影重建：`z = sqrt(1 - dot(xy, xy))`，所以 B 通道可以用来存 AO。
- 高度最小值建议为 **1**，0 会导致部分光影的 POM 出错。
- 从 OpenGL 法线（如 SD 默认输出）转换时，需要翻转 G 通道。

## _s 高光贴图

| 通道 | 含义 | 编码 |
|---|---|---|
| R | 感知光滑度 | 0 = 粗糙，255 = 光滑；`roughness = (1 - smoothness)^2`，`smoothness = 1 - sqrt(roughness)` |
| G | F0 或金属 ID | 0–229：F0，线性（v1.3 起，之前是平方根编码），229 ≈ 90%；230–254：预设金属；255：以反照率作为 F0 的自定义金属 |
| B | 孔隙度 / 次表面散射 | 0–64：孔隙度，线性 0%–100%（吸水后变暗、反射变弱）；65–255：SSS，65 = 0%，255 = 100% |
| A | 自发光 | 线性；0 = 不发光，254 = 100%；**255 被忽略**（没有 alpha 的 RGB 图默认就是 255）；发光颜色取自反照率 |

## 版本变化

- v1.3：F0 改为线性存储（之前是平方根编码）
- v1.2：修改了 AO 的编码方式
- v1.1：加入预设金属，重新安排自发光、SSS、孔隙度的通道
- v1.0：2019 年 4 月首次发布

## 常见换算（非规范原文，属于通用经验）

- 常见非金属 F0 约 2%–5%，对应 G ≈ 5–13（例：F0 = 0.04 → 10）
- 孔隙度和 SSS 共用 B 通道，所以同一像素只能取其中一个
