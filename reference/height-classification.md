## 2. 高度的三个基本规律

### 2.1 高度按"原始像素"成块，并且是阶梯状的

- 每个 8×8 色块内部的高度是同一个值，没有平滑过渡。
- 高度值落在固定的台阶上：624 张里 280 张的台阶是 4，176 张的台阶是 8（即 255、251、247……或 255、247、239……）。
- 一张贴图通常只用 6–11 个不同的高度值（中位数 8）。
- 例外：羊毛和混凝土粉末用了 27–48 个连续的值，看起来是噪声生成而不是分层绘制。

### 2.2 高度值可以换算成"几个像素深"

LabPBR 的满量程 255 对应 25% 方块深度，也就是 16 像素贴图里的 4 个像素。所以：

- 深度（像素）= (255 − A) / 63.75
- **A = 191 正好是 1 个像素深**，A = 127 是 2 个像素深，A = 63 是 3 个像素深
- 台阶 4 相当于 1/16 像素，台阶 8 相当于 1/8 像素

这解释了 190 这个下限：普通表面的起伏不超过 1 个像素深。

### 2.3 高度主要跟着反照率的亮度走

- 624 张里，高度和反照率亮度的相关系数中位数是 0.89，四分之三的贴图高于 0.51。也就是亮的像素高，暗的像素低。
- 相关性低或为负的贴图（约 70 张）都有"结构覆盖"，高度是按形状画的而不是按亮度算的：
  - 砖块：灰缝颜色浅但位置最低
  - 原木顶面：年轮按同心环分层
  - 煤矿、红石矿、青金石矿：矿物颗粒颜色深但被抬高到 255
  - 工作方块（观察者、活塞、合成器、切石机等）：按面板和开口的形状分层

## 5. 归纳出的分类依据

决定一个方块高度下限的因素，按影响从大到小：

1. **是不是完整的不透明方块面**。不是的话没有高度（档位 0）。
2. **有没有真实的开口或凹洞**。有的话开口内部单独设 1.5–3 个像素深（档位 6），其余部分按下面的规则走。
3. **表面的加工程度**。同一种材料，加工越精细，下限越高：
   - 圆石 199 → 石头 207 → 磨制安山岩 235
   - 原木树皮 191 → 木板 207 → 去皮原木 227–239
   - 深板岩 199 → 深板岩砖 207 → 深板岩瓦 211
   - 铜块 195 → 切制铜 203
4. **材料的颗粒粗细和软硬**。粗糙松散的更深，细腻柔软的更浅：
   - 砂土 167、下界岩 175、沙砾 191、泥土 199、沙子 219、泥巴 223、雪 239
5. **有没有明确的边框、缝隙或拼接线**。缝隙和边框是整张贴图的最低点：
   - 木板、砖、石砖的缝都落在 207
   - 铁块、命令方块、工作台这类带厚边框的落在 183
6. **同一方块的不同面可以不同档**：
   - 原木：顶面 167，侧面 191
   - 砂岩：侧面 207，顶面 239
   - 草方块：侧面 199，顶面 231
   - 熔炉：正面 71，侧面 205，顶面 195

## 6. 其他观察

- 上限几乎都是 255（624 张里 594 张）。例外是石头、深板岩、下界岩这几种（上限 231），整体被压低了一截。
- 档位越浅，高度和亮度的相关性越高（档位 2 的中位数 0.97，档位 6 是 0.70）。也就是光滑表面基本纯靠亮度，深的表面有更多手工结构。
- 同一类颜色变体（16 色陶瓦、16 色羊毛）使用完全相同的下限。
- 氧化阶段不改变下限（铜块四个阶段都是 195，切制铜都是 203）。
