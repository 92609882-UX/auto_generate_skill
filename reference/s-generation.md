# `_s` 贴图各通道的生成规律

数据来源：零雾构想 v5003 主包的 1240 张 128×128 方块 `_s` 贴图（1049 张为 RGB，191 张带 A 通道）。
"亮度"指底色贴图的 0.299R + 0.587G + 0.114B。

## 0. 原则（作者说明）

- 各通道基本都依赖底色：根据材质信息，把底色贴图的灰度控制到某个范围内。
- 例外是同一张贴图里个别 8×8 块的材质发生突变（例如木门上的金属把手），这些块的 R、G 通道要单独取值。
- 参考材质包的 R 通道叠加了 HBAO。我们不叠加。

## 1. 四个通道的总体情况

| 通道 | 含义 | 实测特征 |
|---|---|---|
| R | 光滑度 | 跟随底色亮度，每张贴图约 37 个不同的值 |
| G | F0 或金属 | 1240 张里 999 张整张是同一个值 |
| B | 孔隙度或次表面散射 | 1240 张里 1060 张整张是同一个值 |
| A | 自发光 | 1049 张不发光（整张 255 或没有 A 通道）；191 张里有发光像素 |

## 2. R 通道：光滑度

### 2.1 是底色亮度的线性重映射

- 光滑度和底色亮度的相关系数中位数是 0.90（按 8×8 块中心取样）。
- 石头是最干净的例子：亮度 102 对应 R 约 52，亮度 143 对应 R 103，相关系数 1.00，斜率约 1.3。
- 也就是把底色亮度的最小值到最大值，线性映射到该材质的 R 下限到上限。
- 斜率因材质而异：中位数 0.36，十分位到九十分位是 0.08 到 1.3。光滑材质的斜率小（范围窄），粗糙天然材质的斜率大。
- 5% 的贴图斜率为负，17% 的贴图相关系数低于 0.5，都是有结构修正的贴图。例：红砖（灰缝亮但粗糙，斜率 −1.4）、煤矿石。

### 2.2 参考包里叠加了 HBAO（已确认，我们不采用）

- 扣掉亮度的线性部分之后，R 的残差和 `_n` B 通道（AO）的相关系数中位数是 0.61。
- 以石头为例：同一个亮度的块里，被遮蔽的像素 R 值比未遮蔽的低 5–8。R 对 AO 的斜率约 0.25。

## 5. A 通道：自发光

- 不发光的贴图整张为 255，或者干脆没有 A 通道。
- 有发光的 191 张贴图里，只有发光的像素写入小于 255 的值，其余像素保持 255。
- 发光像素的值有两种情况：整块同一个值，或者在一个范围内分级（看起来同样是按底色亮度映射到一个范围）。

| 贴图 | 发光像素占比 | A 值 |
|---|---|---|
| 钻石矿、铁矿、红石矿（矿物颗粒） | 15%–25% | 47–95，分级 |
| 结构方块 | 39% | 64 |
| 命令方块 | 4% | 96 |
| 哭泣的黑曜石 | 25% | 96、112、127 |
| 海晶灯 | 100% | 96–107 |
| 火把（火焰） | 2% | 127 |
| 南瓜灯（面部） | 32% | 140–200 |
| 荧石 | 100% | 167–223，分级 |
| 蛙明灯顶面 | 100% | 183–223，分级 |
| 刷怪笼 | 1% | 191 |
| 末地烛 | 23% | 223 |
| 灯笼 | 15% | 111–247 |
| 菌光体 | 100% | 64–254 |
| 信标 | 100% | 128–254 |
| 岩浆块 | 100% | 3–159 |

规律：光源本体（荧石、蛙明灯、信标）的值高，装饰性的微光（矿物颗粒、结构方块）的值低。

## 6. 混合材质的贴图

G 通道不是整张同值的贴图有 241 张，对应作者说的"个别块材质突变"。例：

- 木门、活板门、木桶：木头部分 G = 0，金属件 G = 232
- 书架、工作台、制图台、制箭台：木头 G = 0，金属件 G = 255
- 矿石：石头部分 G = 0，矿物颗粒取对应矿物块的值（钻石 219、铁 236、金和铜 255、绿宝石 64、青金石和红石 32）
- 铜灯：金属部分 230–255，灯芯 32

## 7. 推测的生成流程

1. 确定贴图的材质，查出该材质的 R 范围、G 值、B 值。
2. R：底色亮度线性映射到 R 范围。有结构修正的贴图（砖缝等）单独处理。不叠加 HBAO。
3. G、B：整张填该材质的固定值。
4. 混合材质的贴图：圈出材质不同的 8×8 块，这些块的 R、G（必要时 B）换成另一种材质的值。
5. A：不发光的填 255。发光的贴图圈出发光像素，填固定值，或者按底色亮度映射到该光源的强度范围。
